<h2>Description</h2>
<p></p>Designed and built a multi-page, responsive business website for a custom home theater and audio installation company using HTML, CSS, and JavaScript. I structured the site with clear separation of concerns, pairing page-specific HTML files with modular CSS stylesheets and shared global styles. I implemented responsive layouts using Flexbox, CSS Grid, and detailed media queries to ensure usability across desktop, tablet, and mobile devices.</p>
<p>I developed client-side JavaScript to handle site navigation and integrated a fully functional contact form using EmailJS, including form validation and user feedback for successful and failed submissions. The project emphasizes accessibility-conscious styling, consistent branding, and maintainable front-end architecture while presenting real client content such as service offerings, image galleries, and contact information in a polished, professional format.</p>
<p>Note: The underlying code, layout, and functionality are complete. Remaining work is limited to final content and image additions.</p>
